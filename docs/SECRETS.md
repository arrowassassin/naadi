# Secrets and configuration

Every runtime value Naadi reads, where it comes from, and what it is called in each place. Values are never committed, logged or printed.

**Load order** (`apps/api/naadi_api/settings.py`, `scripts/check_env.py`): process environment first, then `.env` in the repo root as a local-dev fallback (gitignored). The template with comments is [`.env.example`](../.env.example).

**Where values live:**

- **Claude Code cloud environment:** environment variables in the environment settings (used by this build session).
- **Hugging Face Space** `arrowassassin/naadi`: Space _secrets_ (private) and _variables_ (visible to anyone who can see the Space). `scripts/push_space_secrets.sh` syncs them.
- **GitHub Actions:** exactly one repository secret, `HF_TOKEN` (deploy to the Space, live smoke). The repo is public, so CI holds nothing else: DB tests run against a `supabase/postgres` service container and every other value lives on the Space. Public config CI needs (Space ID, URLs) is written in the workflow files, not stored as Actions secrets or variables.

Kind: **secret** = private everywhere. **public** = may reach the browser. **config** = non-secret server setting.

## Commands

Verify everything (prints pass/fail only, never values; the Tavily check costs 1 credit):

```bash
uv run scripts/check_env.py
```

Push to the Space (asks for confirmation; `--dry-run` lists names only):

```bash
scripts/push_space_secrets.sh
```

GitHub Actions needs exactly one secret, added once by hand: GitHub → the repo → **Settings → Secrets and variables → Actions → New repository secret**, name `HF_TOKEN`, value a Hugging Face **write** token. CI fails loudly, naming `HF_TOKEN`, if a job that needs it runs without it. Nothing else goes into Actions.

## Rotation

See `docs/RUNBOOK.md` → "Rotate secrets" (written in the Ops segment). In short: create the new value at the source, update the cloud environment, re-run `scripts/push_space_secrets.sh` (and, for `HF_TOKEN`, replace the Actions secret in GitHub settings), restart the Space, run `check_env.py`, then revoke the old value.
