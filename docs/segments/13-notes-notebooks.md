## Scope
### Data (one Alembic migration with RLS; update the RLS coverage test + live_check if a table is added)
- `notes` gains `kind ('note'|'highlight'|'page')`, `title`, `sort int`, `paper` (page override, same check as `notebooks.paper`), `canvas ('paper'|'whiteboard')`, `body_text` (plain text for search). Highlights: `anchor_type` `section` or `question`, `anchor_pos {from, to, quote, prefix, suffix, revision}` (ProseMirror positions plus a text quote for re-anchoring), `highlight_color`.
- `ink_layers` gains `ocr_status ('pending'|'done'|'deferred'|'failed')`, `ocr_hash`, `ocr_at` (backend-only).
- `notebooks.cover` takes a fixed set of token names. `app_config`: `ink_ocr` (`idle_seconds: 120`, `min_items: 3`, `max_tiles: 4`, `per_user_daily: 40`), flag `notes` on, `ui.nav` gains Notes.
### API (pydantic → OpenAPI → zod; never log note or ink bodies)
- `GET/POST/PATCH/DELETE /api/notes` (filters: `kind`, `color`, `anchor_type`, `anchor_id`, `notebook_id`, `q`), `GET/POST/PATCH/DELETE /api/notebooks`, `POST /api/notebooks/{id}/pages`, reorder. Question anchors are refused (403) until the student has an attempt on that question; section anchors must be visible to the caller.
- On save: `body_text` is extracted from TipTap JSON (and from Excalidraw text elements for whiteboards), then embedded through S07's API (`ref_type 'note'`, owner set). Delete removes the embeddings.
- `ink_ocr` graph (Aegra background run, registered in `aegra.json`): queued by 12b's save path when a layer has been idle `idle_seconds`, has ≥ `min_items` live items and a new `content_hash`. It loads the items (service role), rasterizes them server-side with Pillow (black on white, 1600 px wide, tiles of ≤ 2048 px, ≤ `max_tiles`), makes one `vision`-role call per tile through `llm.py` (purpose `job`), validates `{text, lines[]}` with pydantic, writes `recognized_text` and embeds it (`ref_type 'ink'`). Budget exhausted or the per-user cap reached → `deferred`; a nightly cron retries deferred layers. Settings toggle "Handwriting search (sends ink images to the AI model)", default on; off → no runs and the existing text is cleared.
- "Convert to text" (lasso `onConvertToText`): `POST /api/ink/convert` with the lasso PNG → one vision call → the text comes back for the student to confirm before it replaces the ink with a text box.
### Web
- **Selection toolbar** in the Reader slot S06 reserved, and on question explanations after answering: Highlight (three swatches, each with its word: "Key fact", "Formula", "My mistake"), Note, Card (S10 create dialog prefilled), Ask (only when the assistant flag is on; S14). Highlights render as `highlight` marks with a word for screen readers. They re-anchor by quote when positions drift; one that can't be found is listed as "Detached" in Notes, never dropped.
- **Page-notes panel** in the Reader (Chapter/Tablet/PhoneChapter): one section-anchored note with Type / Write / Both tabs (TipTap editor; a `notebook_page` ink surface keyed by the note id); a bottom sheet on phone.
- **Notes** (`/notes`) per board: notebook list with counts, note sheet (TipTap 3.34.0: headings, lists, bold/italic, the three highlight colours, images from `user-uploads`), recent highlights with source chips (section, question), filter by colour and anchor, search box (S07 local search scoped to notes + handwriting), "Export PDF". Summarise, Turn into flashcards and Quiz me are S14: hidden until the assistant flag is on.
- **Notebooks** (`/notes/notebooks/$id/$page`) per board: shelf of covers, "New notebook" with a paper choice, fixed US Letter pages ("page 4 of 23", add/reorder/delete), paper templates drawn from tokens under the ink: ruled, dotted, grid, Cornell (cue column + summary band), blank. Ink through `useInkLayer('notebook_page', note_id)` with the 12a tools. A page can instead be a **whiteboard**: Excalidraw 0.18.1, lazy-loaded, assets self-hosted (`EXCALIDRAW_ASSET_PATH`, no CDN fonts, CSP unchanged), collaboration/share/export-to-link disabled, scene saved in `notes.body` (debounced; images in `user-uploads`). "Linked: Chapter …" chip when the page is anchored.
- **PDF export** in the browser with pdf-lib 1.17.1 + `@pdf-lib/fontkit` (pin the latest stable, self-hosted Inter/JetBrains Mono): a note, a notebook or a filtered highlight list. Text is laid out from TipTap nodes (paragraph, headings, lists, marks, highlights as tinted rects with a word legend). Ink is vector paths from perfect-freehand outlines on the page's paper template. Whiteboards are embedded as PNG via Excalidraw `exportToBlob`. Nothing is uploaded.
- Search (S07) gains a "Handwriting" group (snippet + link to the surface) and a "Notes" group.
- States for every screen: loading, empty ("No notes yet" + New note), error, offline (edits queue with "will sync"; Dexie like 12b).

## Decisions (lead to check)
- Highlights stay as `notes` rows (`kind 'highlight'`) as S02 modelled them, re-anchored by text quote. Notebook pages are `notes` rows (`kind 'page'`), and their ink is `notebook_page` keyed by note id.
- OCR rasterizes server-side (Pillow) instead of uploading bitmaps (Storage is 1 GB). The images do reach the free vision model, so a Settings opt-out is added, default on.
- Excalidraw freehand is not OCR'd (its text elements are searchable). Image items on paper pages are deferred (images go in typed notes and whiteboards); the toolbar shows no Image tool there.
- AI summary, flashcards-from-note and Quiz me move to S14 (they need the assistant). PDF export runs client-side and adds `@pdf-lib/fontkit`.
